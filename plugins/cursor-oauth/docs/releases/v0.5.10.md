Cursor plugin v0.5.10 fixes Grok 4.6 stalls and repeated tool-result continuations, and includes the previously validated Cursor Agent image-generation bridge.

## Fixes

- Reply to Cursor native `grep_args`, `read_args`, `shell_args`, and `shell_stream_args` with correlated protocol responses. Previously these requests could remain unanswered until `Cursor transport timed out without meaningful progress`, causing clients to retry and repeat partial output. Native filesystem reads and shell commands are not executed on the gateway; the Agent is directed to the caller's exposed tools.
- Mark completed tool results explicitly in both full replay and checkpoint continuations so the Agent can continue the user's request instead of repeating a completed call or preamble.
- Recover from expired or invalid checkpoint state with one fresh replay only when no output, tool call, or tool result has been exposed. Add event-type counts to progress-timeout errors without including prompt or credential contents.
- Complete the Agent image flow: request context, headless image approval, bounded temporary image writes, completed image bytes, and image-only completion. Images are returned under `message.images` or `delta.images` as inline data URLs.

## Compatibility and upgrade

- The supported package remains Linux amd64 and the native CLIProxyAPI plugin ABI is unchanged.
- `cursor_0.5.10_linux_amd64.zip` is the plugin-store package. Its root contains only `cursor.so`; verify it against `checksums.txt` from this release.
- `cursor-plugin-0.5.10-linux-amd64.tar.gz` includes the manual installer, documentation, notices, and an internal binary checksum. The installer retains the previous binary in `.cursor-backups/`. Restart CLIProxyAPI after upgrading.
- Existing credentials, model-disable settings, and OpenCode session data require no migration. Historical duplicate messages are not rewritten.
- Generated images use a CLIProxyAPI Chat Completions extension. Clients must parse `message.images` / `delta.images`; this release does not add `/v1/images/generations` or make clients that ignore those fields display images.

## Validation

Regression coverage includes bidirectional native-tool replies, streaming and non-streaming image output, bounded image writes, checkpoint recovery, and completed tool-result continuations. Release CI runs the full Go race/shuffle test suite and `go vet`, then builds and packages a clean Linux amd64 shared library from the tagged commit.

The fixes were exercised on the deployed Grok 4.6 path before release: the grep/read reproduction completed in 7.483 seconds streaming and 4.355 seconds non-streaming; an OpenCode-style three-turn tool lifecycle returned its final marker once with no repeated tool calls. These are individual acceptance observations, not latency guarantees.

This is an unofficial community plugin for user-authorized Cursor accounts. Review the bundled `DISCLAIMER.md` before installation.
